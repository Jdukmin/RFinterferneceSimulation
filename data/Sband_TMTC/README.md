# S-band TM/TC antenna patterns (1 deg)

Source basis:
- Beyond Gravity (former RUAG Space) S-band helix TTC antenna datasheet, Internal Code/Doc. 1308999 / 01-24.
- Product variants represented: SBA1 and SBA4.
- Bands: TC/RX 2000-2120 MHz, TM/TX 2200-2300 MHz.
- Public datasheet provides typical measured radiation-pattern envelopes (min/max over frequency and hemisphere).

Generation basis:
- These files are the 1-degree resampled form of the previously prepared v2 screening profiles.
- v2 used the conservative co-pol upper/max envelope approximated from the public datasheet plots at 10-degree anchor spacing.
- 1-degree values are generated by linear interpolation between the existing 10-degree v2 anchors; the anchors themselves are unchanged.
- 0-180 deg is mirrored to 181-359 deg under the same axisymmetric approximation used in v2.
- XZ and YZ files are identical because the public source gives hemisphere envelope plots rather than independent XZ/YZ numeric cuts.

CSV schema:
```text
theta,gain
0,3.800
1,3.770
...
```
- theta: degrees, canonical 0 <= theta < 360
- gain: dBi
- compatible with `rfscreen.patterndata.CsvPatternImporter`

Files:
- SBA1_TC_XZ.csv / SBA1_TC_YZ.csv
- SBA1_TM_XZ.csv / SBA1_TM_YZ.csv
- SBA4_TC_XZ.csv / SBA4_TC_YZ.csv
- SBA4_TM_XZ.csv / SBA4_TM_YZ.csv

Usage note:
These are datasheet-derived approximate screening patterns, not manufacturer-supplied numeric pattern tables or certified 3D measurement data.
