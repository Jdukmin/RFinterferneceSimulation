# L-band GPS/GNSS antenna patterns (1 deg)

Source basis:
- Beyond Gravity Extended GNSS PEC Antenna public GNSS receiver antenna datasheet.
- Public figures provide typical measured radiation-pattern envelopes, including co-pol min/average/max and cross-pol information.
- Screening profiles represented here:
  - L5/E5a: 1176 MHz public plot
  - L2-band proxy: 1207 MHz public plot
  - L1/E1: 1575 MHz public plot

Generation basis:
- These files are the 1-degree resampled form of the previously prepared v2 screening profiles.
- v2 follows the conservative co-pol upper/max envelope digitized from the public datasheet plots at 10-degree anchor spacing.
- 1-degree values are generated by linear interpolation between the existing 10-degree v2 anchors; all original v2 anchors are unchanged.
- 0-180 deg is mirrored to 181-359 deg under the same axisymmetric/hemisphere-envelope approximation used in v2.
- XZ and YZ are identical because the public source provides hemisphere-envelope plots rather than independent numeric XZ/YZ cuts.

CSV schema:
```text
theta,gain
0,7.800
1,7.770
...
```
- theta: degrees, canonical 0 <= theta < 360
- gain: dBi
- compatible with `rfscreen.patterndata.CsvPatternImporter`

Files:
- Extended_GNSS_PEC_L5_1176MHz_XZ.csv / YZ.csv
- Extended_GNSS_PEC_L2_proxy_1207MHz_XZ.csv / YZ.csv
- Extended_GNSS_PEC_L1_1575MHz_XZ.csv / YZ.csv

Important L2 note:
The older Beyond Gravity documentation refers to L2 in the surrounding description, while the middle public radiation-pattern graph itself is labelled 1207 MHz. Therefore the 1207 MHz CSV is retained as an L2-band RFI screening proxy and must not be interpreted as manufacturer-certified GPS L2 1227.60 MHz numeric pattern data.

Usage note:
These are datasheet-derived approximate screening patterns, not manufacturer-supplied numeric pattern tables or certified 3D measurement data.
