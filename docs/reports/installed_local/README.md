# Local installed-pattern model — cropped facets (L- and S-band antennas)

**Status: installed patterns are NOT produced yet.** This folder holds the *geometry input* for a local
(per-antenna) installed-pattern EM model, as decided for the L/S bands (X-band, Ka and SAR stay
free-space). No CST run was made by this step.

Files: `facets_<ANTENNA>_R<radius cm>.csv` (cropped polygons in the antenna-local CST frame) and
`facet_summary.csv` (areas and the **separately reported** distances). Antennas: SBA_NADIR, SBA_ZENITH,
GPSA_1, GPSA_2; half-sizes 0.25 / 0.35 / 0.50 m (extent-convergence set). Generated by
`examples/rfc_level_report.m` (`mission.LocalFacetExporter`) from the SSOT hull; the installation
reference points are **not** snapped, the actual rear panel #8 (X = 0) is included whenever it falls in
the box, and no brackets, cables or radomes are modelled.

Local frame: `+X_L = +X_B`, `+Z_L = boresight (panel normal)`, `+Y_L = +Z_L × +X_L`, origin = reference
point; `v_L = R_BL' (v_B − p_B)`.

## What the geometry shows

- **SBA_NADIR** (panel #6): plane distance 190.2 mm, but the **foot point lies outside the finite
  panel** (it sits beyond the V61 corner): minimum distance to the finite facet is 245.8 mm. The nearest
  structure is an edge/corner, not a flat panel under the antenna. The rear panel #8 enters the box only
  from R = 0.35 m (plane distance 255 mm).
- **SBA_ZENITH** (panel #4): plane distance 161.7 mm; nearest facet/edge 280.2 mm (corner region again).
- Cropped areas are small at these radii (a few hundred cm² per panel), i.e. the local model is a corner
  of the hull, consistent with the planning result that only ≈ 0.7 m boxes are meshable at S-band.

## Why no installed pattern yet

1. A CST application is running on this PC and the CST workstream (`cst/WORKLOG.md`, 2026-10-04 scope
   update; `docs/reports/cst_learning_installed_sband.md`) already owns the installed S-band stage and its
   own convergence plan; a second automation session on the same CST instance was **not** started to
   avoid corrupting its open project.
2. The planning result (`docs/reports/em_sweep/`) shows the accepted S-band helix model (79 376 cells
   alone) plus a 0.7 m hull box exceeds the Learning Edition limit; a local model needs a reduced antenna
   or smaller box, and its convergence (R3/R4/R5) cannot be demonstrated within 100 k cells.

## How results plug in

Accepted installed cuts (1-degree XZ/YZ, source convention) go into
`data/spacecraft/simplified_spacecraft_v1/installed_patterns.csv` (status `ACCEPTED`); the case builder
then loads them as `antenna.InstalledPattern` (never touching the frozen free-space files), and the level
report flags the affected pairs `INSTALLED_PATTERN`. A tabulated S21 goes through
`coupling.CstCouplingModel` instead (`RfcLevelReport.couplingModel(tables)`).
