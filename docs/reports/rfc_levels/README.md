# Received level (S21) of every interferer → victim pair

Generated by `examples/rfc_level_report.m` (`mission.RfcLevelReport`) with the existing engine;
`rfc_levels_all.csv` = 6 cases × 3 modes = 164 pair rows. Terminology: see
`docs/notes/kari_terminology_status_2026-10-04.md` (**provisional**, not yet confirmed against the KARI
papers — 간섭원 = interferer, 피간섭원 = victim).

## Method and policy

- **Coupling policy (owner, 2026-10-04): X-band (ISL), Ka and SAR use free space.** L/S use an installed
  pattern / S21 *where one exists* — **none has been accepted yet**, so every row is free-space and the
  `installed_effect` column says so (`FREE_SPACE_BY_DECISION` for X/Ka-frequency interferers,
  `FREE_SPACE_INSTALLATION_EFFECT_UNKNOWN` for S-band interferers).
- **Transfer** `S21 = Gtx + Grx − FSPL` (frozen free-space patterns toward each other, Friis). **Received
  level** at the victim antenna port = `P_tx + S21` (broadband). **Required rejection** = received level −
  allowable in-band level (`kTB + NF + I/N_max`, I/N_max = −6 dB): the out-of-band rejection the victim
  front end must provide.
- **Far field:** `far_field_verified = 1` where `distance ≥ 2D²/λ` (S-band, GPS, ISL); for **every Ka
  row it is 0** (2D²/λ ≈ 8 m at 26 GHz > any on-board distance). Those rows are `FREE_SPACE_ASSUMED`:
  Friis applied by the owner's decision, an estimate. 88 of 164 rows are far-field verified.
- **LOS** is geometry evidence only. `BLOCKED` pairs (path through the hull) still carry the free-space
  level, i.e. an **upper bound** for them (shadowing would lower it), never a computed loss.
- Same-mount pairs (e.g. TM → TC of one SBA, ISL TX → ISL RX) have no inter-antenna path and are omitted.

Findings:
1. **The S-band telemetry transmitter dominates.** The SBA_ZENITH TM puts about **−14 dBm** at the GPS L1 antenna
   port (GPSA_1) against a GPS signal near −128.5 dBm and an allowable in-band level of −104.9 dBm; the GPS
   front end would have to reject the S-band signal by ≥ **90.7 dB**. Whether it does (preselector, LNA
   compression/blocking) cannot be judged: P1dB/IIP3/blocking data are unknown.
2. **All pairs are out of band** in this baseline, so there is no in-band interference power; the relevant
   quantities are the received level and the required rejection (a blocking / compression question).
3. **The strongest path is exactly where free space is least trustworthy.** SBA_ZENITH and GPSA_1/2 sit on
   the same side of the hull, ~88° off the SBA boresight (grazing along the surface). The installed pattern
   there differs from the free-space one — this is the first thing an installed-pattern study should settle.
4. SBA1 vs SBA4 changes the S-band levels by ≈ 0.3–6.7 dB (SBA_NADIR → GPSA_1: −75.7 vs −79.6 dB; → GPSA_2: −73.7 vs −80.4 dB; SBA_ZENITH ≈ 0.3 dB).
5. Nominal modes lower the exposure only by removing the second SBA / KAA: with `NOM_NADIR_KAA1` the worst
   level at GPSA_1 is −38.7 dBm; with `NOM_ZENITH_KAA2` it stays −14.2 dBm (the zenith SBA is the culprit).
   The nominal modes are provisional templates.
6. L2/L5 cases have no GPS receiver (only the L1 baseline exists); the S/ISL/Ka rows are present for all six.

## Caveats

Frozen free-space patterns (datasheet envelopes; L2 = 1207 MHz proxy; ISL/Ka surrogates); no polarization
mismatch, no installed effect, no scattering; single frequency pattern reused across the band; GNSS
criterion is thermal I/N (temporary).
